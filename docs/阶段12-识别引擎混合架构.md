# 阶段 12：识别引擎混合架构——VLM 结构化解析（v0.14.0）

> **状态**：⬜ 未开始 ｜ **前置**：无硬依赖（阶段 11 可并行；本阶段不碰其改动面）｜ **依据**：`docs/VLM结构化解析对比.md`（2026-09-14 A/B 实测，决策门已过）+ 阶段4 评估预注册的「~80 分天花板」+ `提取质量体检.md` 标题根治二期的补丁跑步机复盘
> **目标一句话**：数字页的文本与公式提取主路径换成「区域快照+遮罩 → PaddleOCR-VL 整页结构化解析 → 交叉校验降级」混合架构，公式以 LaTeX 呈现、复杂版式页内容完整度提升——重排版左右对照/紧跟/原版对照三模式共用管线，一次受益。

---

## 1. 背景与证据

- **A/B 实测（4 篇真实论文 × 12 页，2026-09-14）**：PaddleOCR-VL-1.5 整页结构化解析 vs 现行 textlayer（pymupdf4llm classic + 启发式，v18）——
  - 公式：**0 → 40 段定界 LaTeX**（`\(...\)`/`\[...\]`，与前端 `preprocessMath`→KaTeX 链路天然兼容）；Attention p4 招牌公式逐字符正确；
  - 复杂版式页内容完整度（bag F1）：DALK p1 0.976→0.996、FG-RAG p1 0.960→0.997、Survey p1 0.977→0.995——正是现行补丁最吃力的标题/作者区页型；
  - 双栏顺序：可测 5 页 B 1.0×4+0.79 vs A 1.0×3+0.667×2（反例 DALK p2 整栏交换，内容完整，需几何兜底）；
  - 表格：hosted 版整页提示下**全部丢弃**（元素级「Table Recognition:」实验也不可用）→ 维持 v5 用户决策（表格=快照图）+ 送 VLM 前打白遮罩；
  - 截断 0/12 页、平均 6.4s/页、两轮重跑数值一致（近似确定性）、免费档零成本。
- **现行架构天花板实证**：TEXT_LAYER_MODEL v2→v18 十六个版本的补丁迭代；标题根治二期自认「每条规则都从个案倒推、只对见过的形态负责」；阶段4 评估预注册的 Markdown 重建路线 ~80 分天花板已被 v13→v18 的实战验证。
- **三模式共用管线**：`parallel`（bilingual/inline 两子模式）与 `original_click` 的 bbox 标注、译文全部消费同一份提取+翻译产物；`original_bilingual`（BabelDOC）已效果好且不动。
- **翻译侧独立证据**（WMT25 findings + BabelDOC/沉浸式翻译生产实现，2026-09 调研）：`<<<n>>>` 分隔符批量是已知反模式（弱模型上回声/段融合高发），生产级做法是 JSON 数组结构化 I/O + 单段回退 + temperature=0。

## 2. 范围

**做**：VLM 解析模块、图表区域遮罩与快照协同、文本层交叉校验降级、管线接入与缓存熔断、噪音过滤与顺序几何兜底、翻译协议升级（JSON 数组+单段回退）、翻译质量档位（可选配置，默认档保持免费）
**不做**：表格结构化转 markdown/HTML（维持快照，远期再评估）；本地布局模型 / MinerU 自建端点；BabelDOC 解析能力内嵌复用（AGPL+内部 API，维持子进程导出定位）；重排版前端渲染改造（KaTeX/markdown 管线已就绪）；原版对照模式 UI 改动

## 3. 任务分解

- [ ] **T1 VLM 解析模块（新建 `backend/ocr/vlm_parse.py`）**
  - 从 `tools/ab_textlayer_vs_vlm_parse.py` 的验证代码转正：`_vlm_call`（payload 与生产扫描页通道完全一致，保留 finish_reason）、截断按栏对半重发（栏检测复用几何判定，单栏页上下对半）；
  - 页级缓存沿用 `ocr_key(pdf_hash, page, model)`（伪模型名独立于 textlayer/视觉 OCR 缓存，含版本后缀）；
  - 单测：mock httpx 响应的截断重发、空输出、HTTP 错误路径。
- [ ] **T2 区域遮罩与快照协同（`backend/ocr/textlayer.py` 提取函数旁路新增）**
  - 快照照旧（`_snapshot_figures` 不动，v5 表格=快照决策维持）；新增「遮罩渲染」：用 `_figure_regions`（光栅+矢量簇+find_tables，含 `_MERGE_GAP` 合并与外扩/表头吸收后的最终区域）在页面副本上 `draw_rect` 白底，再渲染送 VLM——实验已证不能只用 `get_image_rects`（矢量图标签在光栅 bbox 外）；
  - sidecar JSON 与 caption 锚定插回逻辑保留（快照引用插入 VLM 输出的 markdown，锚定用 VLM 输出中的 caption 文本，`_find_para_pos` 复用）。
- [ ] **T3 交叉校验降级（新建 `backend/ocr/verify.py` 或并入 vlm_parse）**
  - 真值=该页文本层字符流**扣除快照区域文本**（复用 `_figure_inner_text_rects` 的区域文本提取）；bag F1 < 0.90 的页回退现行 textlayer 输出并日志留痕（最坏情况=现状，内容完整兜底）；
  - 阈值可配；降级计数进 job stats（前端进度页可见降级页数）。
- [ ] **T4 管线接入与缓存熔断（`backend/pipeline/processor.py`）**
  - `_load_or_run_ocr`：数字页优先 VLM 路线（遮罩→解析→校验→降级），扫描页维持既有视觉路线（同模型同提示，行为天然统一）；
  - `TEXT_LAYER_MODEL` v18→v19 熔断（翻译缓存按 text_hash 键控，未变化文本免重译，沿用 v17/v18 经验）；
  - 首页可见时延验收：页级流式下 ≤10s。
- [ ] **T5 顺序兜底与噪音过滤（`textlayer.py` / `processor.py` 小改）**
  - 高置信双栏页（几何列检测触发条件与 `_column_reading_order` 一致）对 VLM 输出段落做顺序校验/重排（DALK p2 整栏交换反例的兜底）；
  - 残留页码/孤立数字行由现有 `split_into_blocks` 的 `_NOISE_BLOCK` 处理，验证覆盖；
  - 保留：标题几何检测、页眉剔除、跨页续段合并、`_GENERIC_HEADINGS`；预期退役（按回归数据逐项确认后删）：`_demote_sentence_headings`/`_fix_italic_superscripts`/`_split_glued_columns`/`_column_reading_order` 主路径（降级为 T5 兜底）/前端 `mathFragment.ts` 碎片启发式。
- [ ] **T6 翻译协议升级（`backend/translate/providers/openai_compat.py`、`translate/sanitize.py`）**

## 4. 验收标准（全部满足才算完成）

1. **公式**：4 篇样本论文（DALK/FG-RAG/Attention/Survey）中数学 span ≥5 的页，VLM 路线输出定界 LaTeX 段数 ≥1；抽 20 段人工目检正确率 ≥90%。
2. **内容完整度**：交叉校验后终态 bag F1 ≥0.95 的页占比 ≥95%（A/B 脚本口径，快照区域文本已从真值扣除）。
3. **阅读顺序**：几何列检测触发的双栏页，顺序得分 =1.0 占比 ≥90%（T5 兜底生效后）。
4. **降级路径**：mock VLM 空输出/低质输出（bag <0.90）时管线自动回退 textlayer，任务不失败且 stats 记录降级页数。
5. **性能**：数字 PDF 上传后首页可见 ≤10s；同文件重跑（缓存命中）<1s。
6. **翻译协议**：JSON 协议下全篇段融合触发 0 次；回声块数不高于 pv5 基线；`pytest` 全过、`npx tsc --noEmit` 通过、`python -m compileall backend/ -q` 通过。
7. **人工验收**：DALK 与 FG-RAG 删除缓存全文重翻，三模式走查（公式渲染/段落顺序/表格快照/标题/图表位置），用户确认通过。

## 5. 风险与缓解

| 风险 | 缓解 |
|------|------|
| hosted 模型升级导致输出格式漂移（`\(\)`→其他定界等） | 缓存键含模型名+版本后缀；交叉校验兜底；A/B 工具固化为回归 |
| 免费档限速（RPM/TPM）影响长文档 | 沿用并发上限+429 退避；页级缓存；长文档「纯文字页本地提取」按需触发列为后续优化位（不在本阶段） |
| 表格页交叉校验误降级（真值含表格文本而 VLM 有意丢弃） | T3 真值扣除快照区域文本后再比对 |
| VLM 顺序偶发整栏交换（DALK p2 实测） | T5 几何列序兜底（高置信双栏页强制/校验） |
| 首页时延从 ~1s 变 ~7s 的体验回退 | 页级流式保持渐进呈现；进度卡文案标注「结构化解析中」；缓存后秒开 |
| 首跑批翻译协议切换引入新失败形态 | T6 单测覆盖缺段/融合/非 JSON 输出路径；pv6 熔断可整体回退 pv5（配置项保留旧协议代码一个版本） |
| 打包回归 | 无新增依赖（httpx/pymupdf 均已在 sidecar）；build-exe 照常回归 |
