## 环境要点（新电脑必读）

- 后端：项目根 **`.venv`** 的 python 跑 `backend/main.py`（127.0.0.1:8000）；前端 `npm run dev`（5173，浏览器桥接模式）或 `tauri dev`（完整桌面体验；capability 变更需重启重编译）
- **`.venv` 与 `.venv-babeldoc` 不进 git，新机器必须重建**：
  - `.venv`：装 backend requirements（fastapi/uvicorn/pymupdf 等）
  - `.venv-babeldoc`：系统 Python 3.12 → `python -m venv .venv-babeldoc` → 其 Scripts/pip 安装 `BabelDOC==0.6.4`（依赖大，约 30-40 分钟；详见 docs/阶段9 文档 T0 记录）
- 用户数据：`%APPDATA%/pdf-reader/`（config.json 含 SiliconFlow API 配置、cache/ 含翻译缓存与 babeldoc 产物、docs_index.json）
- 免费档：SiliconFlow `Qwen/Qwen3-8B` 翻译 + `PaddlePaddle/PaddleOCR-VL-1.5` OCR（OCR max_tokens ≤8192）
