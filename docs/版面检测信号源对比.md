# 版面检测信号源对比：字号规则 vs DocLayout-YOLO（T9 决策依据）

- 日期：2026-09-14 ｜ 模型：DocLayout-YOLO（随包 BabelDOC 0.6.4 运行时，`docvision.doclayout`，ONNX 本地推理）
- 诱因：FG-RAG 删缓存重翻人工验收「效果一般」，诊断出三个根因（见 §1）；字号规则路线试修被用户按协作协议第 9 条叫停（个案特调），按决策门流程补齐证据后立项本任务。
- 工具：`backend/tools/layout_model_quality.py`（随包运行时运行，语料路径内置，可复跑）。

## 1. 三个根因（FG-RAG 重翻验收）

| # | 现象 | 根因 | 为什么现行信号无解 |
|---|------|------|------|
| 1 | 全篇零标题层级，"Abstract"/"4.1 Experimental Settings" 都是平文本 | PaddleOCR-VL「OCR:」输出平文本，无 markdown 结构 | 字号/粗体是弱证据：斜体标题、同号粗体、表题全部长一样，规则越补越特调 |
| 2 | p1 版权/引用/venue 段落混在正文（ACM Reference Format、CIKM '25、Permission 段） | 出版商首页套话区域与正文同权 | 措辞无穷尽，文本匹配追着跑（v2→v18 跑步机同款） |
| 3 | p3 三张无框表被 VLM 念成碎行混入正文 | find_tables/cluster_drawings 对无框表 0 候选 → 无遮罩无快照 | 几何规则只认线框/绘图簇，无框表天然不可见 |

## 2. DocLayout-YOLO 实测（类别：title / plain text / abandon / figure / figure_caption / table / table_caption / table_footnote / isolate_formula / formula_caption）

语料 = 调优集 4 篇（FG-RAG/DALK/Attention/Survey）+ **泛化验证 1 篇未见论文**（TransE 2013，目录随机取，零调参）：

| 检测目标 | 结果（置信度） |
|----------|------|
| 节标题/文档标题（title） | **全命中**：各论文文档标题、"1 Introduction"、"4.1 Experimental Settings"、罗马编号 "I. INTRODUCTION"、"C. GraphRAG"，0.84~0.95；未见论文 "2 Translation-based model"/"3 Related work" 0.92-0.93 |
| 版权/噪音（abandon） | **全命中**：Permission 版权段 0.92、CIKM venue 行 0.90、页眉运行头 0.91、arXiv 侧章 0.72、ACL 横幅 0.85、页码 0.76-0.90、脚注——**按区域判定，与措辞无关** |
| 无框表（table） | FG-RAG p3 三张碎行表 0.92/0.76（find_tables 为 0 候选）；**DALK p9 那张曾导致 bag=0.69 降级的无框表 0.97** |
| 泛化 | 未见论文（TransE）标题/脚注/页码全部正确，零调参 |
| 耗时 | ~1.2s/页（含 2x 渲染）+ 首次模型加载 ~2.5s（一次性） |

已知边界（如实）：模型只出 title 单类，无 ##/### 细分——层级用**编号深度约定**定级（页 0 最大 title→#，"4"→##，"3.4"/"3.2.1"→###，学界通用约定，非个案）；低置信重复框（0.3~0.6 的同区域复检）需 IoU+置信阈值去重；"Algorithm 1" 伪代码框被判低置信 table（0.26~0.42，阈值滤除后不误判，但也拿不到快照——登记观察项）。

## 3. 方案对比

| 方案 | 三根因覆盖 | 泛化 | 成本/风险 | 结论 |
|------|-----------|------|-----------|------|
| A. 字号规则（已提交 fb182b5） | 部分：标题/噪音靠规则堆，无框表无解 | 只对见过的版式负责 | 规则数量随论文增长（本会话实证滑向跑步机） | **降级为兜底**（运行时缺失时自动启用） |
| B. 版面模型为主信号 | 全覆盖：title→标题提升、abandon→遮罩+剔除+truth 扣除、table→进快照管线 | 已验证未见论文 | 子进程调入随包运行时 + ~1.2s/页 + 重复框去重 | **推荐采纳** |
| C. 提示词让 VLM 标结构 | 阶段12 立项时已实测元素级提示（"Table Recognition:"→`<ecel><fcel>` 乱码） | hosted 版不遵循结构指令 | 零成本排除 | 否 |

## 4. 决策与任务

**决策（待用户确认）**：采纳 B——版面模型为主结构信号，字号证据（A）自动兜底。**这是信号源更换而非架构更换**：阶段12 提取管线（快照→遮罩→解析→交叉校验→兜底）不变，遮罩/结构证据的来源从手工规则换成模型区域。

任务分解见 `阶段12-识别引擎混合架构.md` T9；执行要点：
- 版面检测跑在随包 babeldoc 运行时（子进程 + NDJSON 流式），**不进主后端 venv**（onnxruntime 打包段错误事故防复发，见 `阶段9`）；
- `abandon` 区域三用：送 VLM 前遮罩、truth 扣除、VLM 输出段落剔除（区域文本匹配）；
- `table`/`figure` 区域并入 `_figure_regions` 候选 → 无框表走既有快照+遮罩管线；
- `title` 区域 → 标题提升（页 0 最大→#，编号深度→##/###）；
- 版面区域按页缓存（伪模型名 `doclayout-v1`），回归重放零成本。
